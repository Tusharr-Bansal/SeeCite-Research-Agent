# 0006 — Decisions are documented in the repo

**Date:** 2026-10-21 · **Status:** Accepted

I record each decision as a numbered file in `docs/decisions/`. When a decision changes, I add a new record instead of editing the old one.

**Why:** the reasoning sits next to the code on GitHub, and keeping old records shows what I tried first and why I changed it.

**Rejected:** a separate document outside the repo. Easier to edit, but it drifts away from the code.
